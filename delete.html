주요 요약 안내
  • 즉시 파기: 앱 내 [회원 탈퇴] 진행 시 본인 계정 정보 및 생성 데이터는 즉시 삭제되어 복구가 불가능합니다.
  • 이메일 요청 지원: 앱 삭제 또는 접속 불가의 경우 이메일 접수를 통해 본인 확인 후 계정 삭제가 가능합니다.
  • 법정 보관: 관계 법령(통신비밀보호법)에 따라 접속 기록은 3개월간 안전하게 보관된 후 자동 삭제됩니다.

1앱 내에서 직접 삭제하는 방법

  • 진행 경로: 앱 실행 → 하단 [내 정보] 메뉴 → 화면 최하단 [회원 탈퇴] 선택
  • 주의사항: 탈퇴 확인 버튼을 누르면 계정과 데이터가 지체 없이 즉시 파기되며, 한 번 삭제된 정보는 복구할 수 없습니다.

2앱 미설치 상태 또는 로그인 불가능 시 요청 방법

앱을 이미 삭제하셨거나 로그인할 수 없는 상황인 경우, 가입 시 사용한 이메일 계정을 통해 아래 이메일로 요청해 주시기 바랍니다.

  • 접수 이메일: ceo@knexm.com
  • 메일 제목/내용: "계정 삭제 요청" 및 가입 이메일 주소 기재
  • 처리 기간: 본인 확인 절차를 거쳐 접수 후 영업일 기준 7일 이내에 안전하게 삭제 처리됩니다.

3삭제(파기)되는 데이터 항목

회원 탈퇴 시 아래의 모든 개인정보 및 서비스 이용 데이터가 즉시 완전 파기됩니다.

  • 계정 정보: 소셜 로그인 인증 정보, 프로필(닉네임, 프로필 사진)
  • 활동 기록: 찜한 목록, 작성한 게시물·댓글, 좋아요 기록
  • 상담 및 신청 데이터: 상담 문의 내역 및 첨부 사진, 관계자 신청 정보 및 제출 서류

※ 관련 법령(통신비밀보호법)에 의거하여 서비스 접속 기록(로그)은 부정이용 방지 및 법적 의무 준수를 위해 3개월간 보관된 후 자동으로 파기됩니다.
